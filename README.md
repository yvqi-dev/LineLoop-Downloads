# LineLoop

这是 LineLoop 的[官网下载页](https://yvqi-dev.github.io/LineLoop-Downloads/)与 macOS 安装包发布仓库。应用适用于 Apple 芯片 Mac 和 macOS 15 或更新版本。

[下载最新版 DMG](https://github.com/yvqi-dev/LineLoop-Downloads/releases/latest) · 拖入“应用程序”即可使用，无需安装命令行工具或模型。

LineLoop 把用户选择的视频整理为可逐句循环的听力练习，支持英语、西班牙语、法语、德语、俄语和中文翻译。语音识别在本机完成。

官网提供简体中文、繁体中文、英语、西班牙语、法语、德语和俄语界面；首页演示可切换五种视频语言。

第三方组件及许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。应用源码保存在独立的私人仓库；本仓库只包含网站和发布资源。
